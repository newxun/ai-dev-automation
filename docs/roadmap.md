# Roadmap

**Language:** [English](#english) | [中文](#中文)

<a id="english"></a>

## English

Long-term direction — not a commitment to build everything at once.

### Near Term

- Add automation tools for high-friction daily dev tasks (review, testing, triage, release).
- Keep new artifacts **English-first**; add Chinese notes where helpful.
- Record failure cases and limitations after each real use.

### Current Inventory (already in repo)

- `artifacts/skills/` — installable/reusable Skills
- `artifacts/agents/` — agent playbooks
- `artifacts/workflows/` — multi-step automation flows
- `artifacts/checklists/` — repeatable quality gates
- `artifacts/evaluations/` — scenario-based validation

### Possible Future Areas

Add when usage justifies it:

- `artifacts/mcp/` — MCP servers, integration guides
- `artifacts/automation/` or `tools/` — scripts, CLIs, runnable utilities
- `artifacts/benchmarks/` — efficiency benchmarks for prompts and workflows

### Review Questions

1. Which artifacts were used in real work this month?
2. Which are ideas only — no value yet?
3. What can be merged or deleted?
4. Which steps can be further automated?
5. What should become a template or checklist?

## 中文

长期演进方向，不代表必须一次性完成。

### 近期

- 为日常高频痛点补充自动化工具（Review、测试、分诊、发布等）。
- 新 Artifact 以 **英文为主**，必要时附中文说明。
- 每次真实使用后记录失败案例与限制。

### 已有内容

- `artifacts/skills/` — 可安装/复用的 Skill
- `artifacts/agents/` — Agent playbook
- `artifacts/workflows/` — 多步骤自动化流程
- `artifacts/checklists/` — 可重复使用的质量门禁
- `artifacts/evaluations/` — 场景化验证

### 未来可能扩展

用量足够时再增加：

- `artifacts/mcp/` — MCP 服务与集成经验
- `artifacts/automation/` 或 `tools/` — 脚本、CLI、可执行工具
- `artifacts/benchmarks/` — Prompt / Workflow 效率基准

### 定期复盘

1. 本月哪些 Artifact 被真实使用过？
2. 哪些只是想法、尚未产生价值？
3. 哪些可以合并或删除？
4. 哪些步骤还能进一步自动化？
5. 哪些经验应沉淀为模板或 Checklist？
