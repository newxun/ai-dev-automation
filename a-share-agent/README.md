# A股导师（a-share-agent）

> ⚠️ **仅供参考，不构成投资建议。** 股市有风险，投资需谨慎，请独立判断并自行承担交易风险。

一个跑在自己电脑上的 **AI 炒股指导老师**，不是行情软件。它不盯盘、不荐股、不报目标价、不自动下单，做的是：

- **盘后复盘**：每天收盘后看你今天的成交，逐笔标记「计划内 / 计划外 / 追涨 / 亏后马上再买」，对账昨天的预案。
- **次日做T预案**：只给明天的条件单式预案（几点前、什么价、多少股、认错位置），不满足条件的直接写「明天不做」；第二天收盘后自动对账。
- **持仓体检 / 去留决策**：仓位、行业扎堆、趋势、财报与事件，算清「继续拿 / 减仓 / 清仓」各自的钱和时间代价（停牌股会按复牌后处理）。
- **交易前冷静对话**：想买想卖之前先过一遍，触发追涨、亏损补仓、冷静期等关卡时会追问理由，并按你的风险上限算最多能买多少股。
- **问导师**：自由提问，模型通过工具查你的持仓和数据；查不到就说查不到，不编。

每张建议都是固定骨架的卡片：**结论 / 依据（带来源和时间）/ 动作 / 认错条件 / 最坏情况（金额和占总资产比例）/ 反方理由 / 数据缺口 / 复查时间**。
分工是：程序算事实、守硬规则 → 模型选择和解释 → 程序生成卡片并复核。模型出错或没配置时，会退回到程序生成的卡片，并标明「导师未参与」。

## 快速开始

需要 Python 3.11+（pandas 3 的要求）。

```bash
cd a-share-agent
./start.sh            # Windows 双击 start.bat
```

首次运行会自动创建虚拟环境并安装依赖，然后打开 <http://127.0.0.1:8600>：

1. 设置访问密码（手机访问也用它）。
2. 回答几道入门问题（资金量、能承受的回撤、能不能盯盘、做T经验……），生成你的硬规则。
3. 「设置 → 模型」里添加模型，点「测试连接」，再点「用考卷试考」，**通过考卷后才能设为默认**。
4. 「持仓 → 导入/更新持仓」上传券商导出的持仓文件，晚上再导入当天的交割单。
5. 首页按「今晚三步」走：确认成交 → 生成复盘 → 看明天的做T预案。

### 没有模型 Key 也想先看看

```bash
./start.sh --demo --mock-llm
```

演示模式使用冻结的真实历史行情和虚构账户（数据单独放在 `data/demo`），模型换成内置的模拟导师。模拟导师只用来演示流程，回答质量不代表真实模型。

也可以单独启动一个本地的 OpenAI 兼容模拟服务，在「设置 → 模型」里按「自定义」接入 `http://127.0.0.1:9876/v1`：

```bash
.venv/bin/python -m ashare_agent mock-llm --port 9876
```

## 手机怎么访问

1. 手机和电脑连同一个 Wi-Fi。
2. 启动时终端会打印局域网地址，「设置 → 手机访问与安全」里也有地址和二维码，例如 `http://192.168.1.23:8600`。
3. 手机浏览器打开，输入访问密码。菜单里选「添加到主屏幕」，就能像 App 一样打开。
4. 打不开时检查电脑防火墙是否放行 8600 端口。

需要加密连接时用 `./start.sh --https`（自签名证书，首次打开要在手机上点「继续访问」）。

**只允许局域网访问。不要在路由器上做端口映射或内网穿透**，否则你的持仓和模型 Key 会暴露在公网。

开机自启：`.venv/bin/python -m ashare_agent autostart`（先加 `--dry-run` 看看会写什么；支持 Linux systemd 用户服务、macOS launchd、Windows 启动文件夹）。

## 换模型

支持任何 OpenAI 兼容接口，内置预设：DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI、硅基流动、Ollama（本地），以及「自定义」。

- **API Key 只存在本机**：勾选「保存到本机配置文件」时写入 `data/config.json`（已在 `.gitignore` 中，不会入库）；不勾则只在本次运行期间有效。也可以用环境变量（如 `DEEPSEEK_API_KEY`，或通用的 `ASHARE_LLM_API_KEY`）。页面上只显示末四位。
- 模型不支持工具调用或 JSON 模式时会自动降级。
- **换默认模型前必须考试**：考卷用冻结的真实行情和虚构账户出题，包括数字与规则、忠实度（不编造）、情景决策、做T预案、脱敏、稳定性。命令行也能考：

```bash
.venv/bin/python -m ashare_agent exam --profile DeepSeek
```

情景决策部分需要人工评分（报告页里填 1–5 分，均分 ≥ 4 才算合格）。

## 导入持仓和成交

- **文件**：同花顺、通达信、东方财富等导出的 CSV / TXT / XLS / XLSX，自动识别表头和编码（GBK/UTF-8）。表头上方的账户信息整段丢弃，可用资金会自动读出。
- **手动**：每行「代码 名称 数量 成本」。
- **截图**：在本机做文字识别（RapidOCR），自动遮盖账号、姓名、手机号等后再让你逐行确认；识别不准时，可以选择只把脱敏后的文字发给模型整理，或在你确认后把打码图片发给视觉模型。
- 所有导入都要逐行确认后才保存。

## 隐私和安全

- **脱敏**：资金账号、股东代码、姓名、身份证、手机号、银行卡、邮箱、合同编号等在导入时就去掉；每次发给模型前程序再做一遍兜底检查。
- **发送记录**：「设置 → 模型 → 查看发送记录」能看到每次发给模型的完整内容。
- **登录**：密码只存 scrypt 哈希；登录有效期 7 天，可退出本设备或所有设备；连续输错 5 次锁定 15 分钟；跨站提交会被拒绝。
- 数据都在 `data/`（SQLite），不会上传任何地方；行情来自 AKShare 公开数据，带超时和缓存，取不到时会在卡片的「数据缺口」里写明。

## 开发

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

测试覆盖：交易费用、涨跌停（主板 / ST / 创业板 / 科创板 / 北交所 / 新股）、T+1、补仓成本、做T盈亏与保本价差、硬规则与冷静关卡、做T预案的硬约束与次日对账、持仓与交割单解析、脱敏（含真实 OCR 截图和发送记录）、导师各任务与「坏模型也破不了规则」、考卷、登录与局域网限制、真实 OpenAI SDK 走 HTTP 调用模拟服务。

考卷快照由 `scripts/build_exam_snapshot.py` 生成（需要联网），已固定在 `ashare_agent/exam/snapshot.json`。

```
ashare_agent/
  market.py rules.py        A股规则、费用、仓位与冷静关卡（纯计算）
  portfolio.py trades.py    持仓 / 交割单解析与对账
  privacy.py ocr.py         脱敏、截图识别与打码
  data_source.py            AKShare 数据 + 冻结快照
  t_plan.py behavior.py     做T预案引擎、交割单行为体检
  cards.py mentor/          卡片骨架、导师任务、问答工具
  llm.py mock_llm.py        OpenAI 兼容客户端、模拟模型
  exam/                     考卷与评分
  web/                      FastAPI 网页（服务端渲染 + 少量原生 JS，PWA）
  scheduler.py              交易日 15:45 自动准备收盘数据
```

为什么用 FastAPI 而不是 Streamlit：手机访问需要登录会话、错误锁定、局域网限制、跨站防护和 PWA，这些在 Streamlit 里很难做好；服务端渲染的页面在手机上也更轻、更快。
